# 流变叠时台（TTS Workbench）

对流变频率扫做时温叠加（Time-Temperature Superposition）的本地工作台。
多条等温曲线可分别调整水平移位 `log10 aT` 与可选竖直移位 `log10 bT`，
并对 WLF 与 Arrhenius 两种移位规律分别拟合，比较不同叠加假设下的局部偏差。

## 安装与运行

```sh
go mod download
go test ./... -count=1 && go run ./cmd/server --listen 127.0.0.1:5520
```

访问 <http://127.0.0.1:5520>，页面标题为“流变叠时台”。
首次启动若数据库（默认 `./tts.db`，可用 `--db` 指定）为空，
按种子（默认 `1183`，可用 `--seed` 指定）生成演示数据。

## 数据口径

- **点**：角频率 ω（rad/s，必须 > 0）、储能模量 G′（Pa）、损耗模量 G″（Pa）、
  相位角 δ（度）。
- **曲线**：一条等温频率扫，含标签与摄氏温度。
- **移位**：约化坐标 `log10 ω_red = log10 ω + log10 aT`；
  勾选“竖直移位”后 `log10 G_red = log10 G + log10 bT`。
  参考温度曲线的移位按定义为 0，不可编辑。
- **一致性检查**：相位角与模量需满足
  `|tan δ − G″/G′| ≤ 容差 × tan δ`。容差在页面上可改，
  并参与运行指纹（SHA-256），不是隐藏常量。
- **自动排除**：频率非正（无法取对数）、模量非正（不能进入对数轴）、
  相位/模量不一致的点自动排除并记录理由；手工排除（如超出线性黏弹区）
  同样必须填写理由。所有排除点可在页面与 `GET /api/exclusions` 反查理由。
- **重叠区误差**：相邻温度曲线在当前手工移位下，于共同约化频段内做
  对数线性插值，报告重叠宽度（decades）、样本数与 G′/G″ 的 RMS 失配。
- **不可识别诊断**：与参考曲线无重叠频段时，不给精确移位（不做外推），
  只给出能产生任意重叠的 `log10 aT` 范围 `[lo, hi]` 与诊断信息。
- **拟合**：WLF（`log10 aT = −C1(T−Tref)/(C2+T−Tref)`，C2 黄金分割搜索 +
  C1 闭式最小二乘）与 Arrhenius（`log10 aT = Ea/(R ln10)·(1/T − 1/Tref)`，
  闭式）分别拟合。拟合样本 = 参考锚点 (Tref, 0) + 未锁定曲线的手工移位；
  锁定曲线不参与拟合且其移位不可编辑。
- **手工值优先**：模型预测与残差（手工 − 预测）只展示与记录，
  绝不写回手工移位。

## 运行指纹与重放

运行指纹由种子、参考温度、容差、全部原始点、手工移位与手工排除
 canonical 序列化后取 SHA-256 得到。相同种子重建（页面“清空并按种子重建”
或重启时空库初始化）得到完全相同的指纹；改任一输入（包括容差）指纹即变。

## 导出 / 导入复核

- `GET /api/export`（或页面按钮）下载 `tts-run/v1` JSON：含完整运行状态、
  指纹，以及派生结果（WLF/Arrhenius 拟合、排除点及理由、可识别性诊断、
  重叠误差）。
- 清空数据库（换种子重建或删除 `tts.db`）后，用页面“导入运行记录”或
  `POST /api/import`（multipart 字段 `file`）重新导入，指纹与导出时一致
  即复核通过；导入会校验引用完整性（曲线/点 ID、非空排除理由、正容差）。

## 演示数据（fixture）

种子决定的三条等温曲线（双模式 Maxwell 模型 + 确定性噪声）：

| 曲线 | 温度 | 频段 (rad/s) | 说明 |
|------|------|--------------|------|
| T25  | 25 °C（参考） | 0.1 – 100 | 含一个相位/模量不一致点（自动排除） |
| T40  | 40 °C | 1 – 1000 | 与 T25 有重叠；含一个非正 G′ 点（自动排除） |
| T60  | 60 °C | 1e4 – 1e6 | 与任何曲线无重叠 → 移位不可识别，仅给范围 |

## 测试

```sh
go test ./... -count=1
```

覆盖：fixture 重放一致性、非正频率/模量拒绝、相位容差检查、
不可识别移位只给范围（T60 为 [-7, -2]）、可识别移位的建议值、
WLF/Arrhenius 参数还原、模型不覆盖手工值、容差参与指纹、
存取/导出-清空-导入的指纹一致性、页面标题与诊断展示。
