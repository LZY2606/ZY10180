# 流变叠时台（TTS Workbench）

本地时温叠加工作台：对多个温度下的频率扫描（储能模量 G′、损耗模量 G″、相位角 δ）
做水平/竖直移位、WLF 与 Arrhenius 拟合，并给出相邻温度重叠区的局部偏差与
不可识别诊断。技术栈：Go + SQLite（`modernc.org/sqlite`，纯 Go）+ HTTP + SVG。

## 安装与运行

```sh
go mod download
go test ./... -count=1 && go run ./cmd/server --listen 127.0.0.1:5520
```

访问 <http://127.0.0.1:5520>，页面标题为“流变叠时台”。
首次启动时若数据库为空，自动导入 `fixtures/sweeps.json`。

可选参数：`--db`（默认 `tts.db`）、`--fixtures`（默认 `fixtures/sweeps.json`）。

## 数据口径

- **曲线（curves）**：一条等温频率扫描，含标签与摄氏温度。
- **点（points）**：`[频率 Hz, G′ Pa, G″ Pa, 相位角 °]`。频率必须大于零，
  导入时即拒绝非正频率；模量非正的点不能进入对数轴，运行分析时自动排除并记录理由。
- **一致性检查**：对每个点比较实测相位角与 `atan2(G″, G′)`，偏差超过
  **相位容差**（运行参数，单位度）即排除。容差不是隐藏常量：它随每次运行
  记录在案并参与运行指纹。
- **手工移位**：每条曲线可设水平移位 `log aT` 与可选竖直移位 `log bT`，可锁定。
  锁定曲线的手工值作为已知锚点参与求解。模型预测永不覆盖手工值，
  二者在移位因子表中分列展示，残差 = 已知移位（手工或求解）− 模型预测。
- **移位求解**：沿相邻温度链传播。重叠区内对 log G′、log G″ 做插值，
  以黄金分割搜索最小化 RMS。解必须落在重叠区内部且重叠宽度 ≥ 0.5 个数量级、
  两侧各 ≥ 3 个样本，否则判为不可识别。
- **不可识别**：两条曲线无重叠频段时不凭外推产生精确移位，只给出
  “可拼接范围”（使两条曲线频段恰好相接的移位区间）与不可识别诊断。
- **模型拟合**：WLF（线性化最小二乘，需 ≥ 2 个非参考已知点，否则报告不可辨识）
  与 Arrhenius（单点即可辨识 Ea）分别拟合；预测与残差按曲线逐条记录。
- **运行指纹**：SHA-256（种子、容差、参考曲线、全部手工移位/锁定、
  用户排除、求解结果、拟合与预测）。相同配置重放必得相同指纹。

## Fixture

`fixtures/sweeps.json` 由种子确定性生成（默认种子 42）：

- 三个温度：30 °C、50 °C（参考）、110 °C，各 25 个频点（0.01–10⁴ Hz）。
- 30 °C ↔ 50 °C 有宽重叠频段（真值 log aT = 2.2）；110 °C 与二者完全无重叠
  （真值 log aT = −7.0）。
- 110 °C 曲线最低频点注入非正损耗模量（G″ = −12.5）；
  30 °C 曲线一点注入相位角偏差 10°。

重新生成：`go run ./cmd/fixturegen -seed 42 -out fixtures/sweeps.json`。
测试会断言重新生成与仓库内文件逐字节一致。

## 重放与复核

- **重放**：页面“运行分析”使用相同种子与容差再次运行，指纹不变；
  对应测试 `TestRunFingerprintReplay`、`TestFixtureReplayDeterministic`。
- **导出**：页面“导出运行记录 (JSON)”或 `GET /export`，包含曲线、点、
  用户状态与全部运行（含结果 JSON 与指纹）。
- **清空重导**：页面“清空并重新导入 fixture”或 `POST /reset`，
  清空数据库后重新导入 fixture；重跑分析指纹与清空前一致
  （测试 `TestResetReimportReplay`）。
- **排除点反查**：页面“排除点”表列出每个排除点的来源（用户/一致性检查）
  与理由；用户排除可恢复，自动排除随每次运行重算。

## 布局

```
cmd/server       HTTP 服务入口
cmd/fixturegen   fixture 再生成工具
internal/rheo    TTS 核心：一致性检查、移位求解、WLF/Arrhenius、运行指纹
internal/store   SQLite 持久化（曲线、点、用户状态、运行记录）
internal/web     页面、SVG 图表与表单端点
fixtures/        固定 fixture（种子 42）
```
